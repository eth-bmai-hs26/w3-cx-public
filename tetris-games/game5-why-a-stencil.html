Takeaway: the stencil sorter learned the shape of a T, not where it sits. Its stencil checks every spot of the tray, so it finds the pattern wherever it shows up. The supplier's sorter learned which squares light up in the training corner, so it only knows those spots. Learning patterns instead of positions is why CNNs became a go-to tool for images.

Why the stencil stays small: it only ever looks at a 3 × 3 patch at a time, and it reuses the same 9 numbers at every spot. The supplier's sorter wires every single pixel straight to the answer, each with its own number.

Takeaway: CNNs are far more efficient for images. A filter has the same few numbers however big the picture is, while a fully connected network needs a number for every pixel. Fewer numbers to learn means a smaller model and fewer training examples needed to learn them, which is a big part of why CNNs made image recognition practical.
